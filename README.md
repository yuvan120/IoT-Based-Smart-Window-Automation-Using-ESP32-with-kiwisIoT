# IoT-Based-Smart-Window-Automation-Using-ESP32-with-kiwisIoT

## 📌 About the Project

IoT-Based Smart Window Automation Using ESP32 with KiwisIoT is an IoT-based home automation project designed to automatically control window operations based on environmental conditions.

Using the ESP32 microcontroller and connected sensors, the system monitors environmental parameters such as temperature, humidity, and rainfall. Based on the sensor readings, the window can be automatically opened or closed using a motor mechanism.

The collected sensor data is transmitted through Wi-Fi to the KiwisIoT platform, where users can monitor environmental conditions and window status through an online dashboard from anywhere.

This project helps improve indoor comfort, supports automated ventilation, and demonstrates how IoT technology can make homes smarter, safer, and more convenient.
